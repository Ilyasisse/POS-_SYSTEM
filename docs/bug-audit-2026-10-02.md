# Repository bug audit — 2026-10-02

Reviewed the application, route handlers, business services, client flows, database schema/migrations, configuration, and existing tests from baseline `904f0f666e4c76d13bdf8e29c5102936c2844058`. The findings below are grouped by shared causes. Each group has its own fix commit and regression coverage.

## Validation and practical limits

All **364 tests across 67 unit and SQL migration integration files passed**. Tests were run directly with `node --import tsx <test-file>` to count individual assertions. Regression tests exercise the real modules with isolated database, transaction, authentication, and delivery adapters. Representative before/after runs reproduced failures against the original code; concurrency cases model the problematic interleavings. The final order API group alone adds 41 tests, 31 of which fail against the original code.

The final production build (`npm run build`), TypeScript (`tsc --noEmit --incremental false`), repository lint (`npm run lint`), and `git diff --check` all pass. Existing React/test lint blockers were corrected in a dedicated validation commit; a scoped purity exception documents the intentional request-time server presence snapshot.

To reproduce the complete test run in Bash:

```bash
for test_file in tests/unit/*.test.ts tests/unit/*.test.mjs tests/integration/*.test.mjs; do
  node --import tsx "$test_file" || exit 1
done
```

Live PostgreSQL/Supabase credentials and signed-in browser sessions were not configured. The build uses placeholder configuration; no production migrations, payments, supplier messages, or email deliveries were performed. Locks and business flows still require a deployment smoke test with the real database and staff/customer accounts.

The current attendance schema supports one approved record per worker/business date. Conflicting second-shift approvals now return an explicit error rather than overwrite evidence. Payroll adjustment periods must fit entirely within the run; this preserves the existing documented alternative creation path.
